# call-5min-timer

ahamo など「1回5分以内の国内通話無料」プラン向けの Android アプリ。発信通話の経過時間を
バイブの回数と通知で知らせ、5分の無料枠を超えそうなときに気づけるようにします。

- **発信のみ対象**（着信では動きません）
- **相手が出た瞬間から計測**（呼び出し中はカウントしません）
- **経過分数と同じ回数のバイブ**（1分=1回、2分=2回…）で、画面を見なくても時間が分かる
- **4分30秒に長めのバイブ＋通知音**で終了間近を予告
- **通知タイミング・種類を自由にカスタマイズ**（定期／スポット、バイブ・音・サイレント）
- **電話帳ナビと共存**（迷惑電話対策の `CallScreeningService` は使いません）
- **OPPO（ColorOS）対策**：常駐せず、発信イベントで起動して終話で即終了
- **アプリ内自動アップデート**（GitHub Releases・固定署名鍵）

| 経過時間 | デフォルトの動作 |
| --- | --- |
| 0:00（相手が出た瞬間） | バイブ1回（短）＋通知 |
| 1:00 / 2:00 / 3:00 / 4:00 | 経過分数と同じ回数のバイブ＋通知（1→2→3→4回） |
| 4:30 | 長めのバイブ（600ms）＋通知音 |
| 5:00 | 設定で「1分ごと / 5分で1回 / 鳴らさない」を選択（既定は5分で1回） |

## インストール

1. [Releases](../../releases/latest) から `call-5min-timer-v0.1.0.apk` をダウンロード
2. 「提供元不明のアプリ」の許可を求められたら許可してインストール
3. アプリを開き、画面の「動作に必要な設定」を上から順に許可

| 設定 | 用途 | 必須 |
| --- | --- | --- |
| 電話の状態（`READ_PHONE_STATE`） | 発信・終話の検知 | ○ |
| 通知の表示（`POST_NOTIFICATIONS`） | 経過とお知らせの表示 | ○（Android 13+） |
| 通知へのアクセス | 相手が出た瞬間（00:00）の検知 | 推奨 |
| 発信リダイレクト | 発信の瞬間に起動 | 推奨 |
| 電池の最適化を除外 | バックグラウンドからの起動を許可 | オフセット方式では必須 |

通知アクセスも発信リダイレクトも無い場合は「計測開始の検知」を**オフセット**にすると、
発信から指定秒後（既定5秒）で計測を始めます。**オフセット方式はバックグラウンドから
アプリを起動するため、電池の最適化を除外していないと計測が始まらないことがあります**
（Android 12 以降のバックグラウンド起動制限のため。アプリ内のガイドから設定できます）。

OPPO（ColorOS）では追加で **電池の最適化から外す** と **自動起動の許可** を設定してください
（アプリ内の「動作チェック＆設定ガイド」にボタンがあります）。オフセット方式を使う場合は
電池の最適化の除外が必須です。

## 仕組み

- `CallRedirectionService`（発信の瞬間・迷惑電話対策とは別枠）と `PHONE_STATE`（補助）で発信を検知
- `NotificationListenerService` で通話アプリの進行中通知を監視し、「発信中」から
  「通話中（`00:00` / クロノメーター開始）」に変わった瞬間を計測開始とする
- 通話中だけ `ForegroundService` が動き、`CALL_STATE_IDLE` か通話通知の消滅で即終了（常駐しない）
- 判定は `TimerEngine` / `CallNotificationParser` という純粋な Kotlin に切り出し、JVM テストで検証

```
app/src/main/java/com/yuushilabs/call5mintimer/
├── core/     TimerEngine・通知ルールモデル・通話通知パーサー（単体テスト対象）
├── data/     DataStore（設定・ルール・ETag）
├── service/  発信検知・通知リスナー・通話中タイマー・バイブ/音
├── update/   GitHub Releases 確認・APK ダウンロード・インストーラ起動
└── ui/       Jetpack Compose（Material 3）画面・ルール編集・設定ガイド
```

## カスタマイズ

- **定期通知**：間隔（秒）、開始〜終了、経過回数に応じたバイブ回数の増加 ON/OFF
- **スポット通知**：任意の経過時刻（例 4:30 / 4:50 / 5:00）に1回
- **鳴らし方**：バイブのみ / 音のみ / バイブ＋音 / サイレント、バイブ長（120/250/600ms）、
  連続間隔、ビープ音または端末の通知音、音量
- **テスト鳴動**：各ルールの「▶」で、電話をかけずにその場で確認
- **プリセット復元**：「ahamo 5分標準」に戻す

## プライバシー

通話の内容・電話番号・通話履歴は保存も送信もしません。`INTERNET` 権限はアプリ内
アップデート（GitHub Releases の確認と APK のダウンロード）だけに使います。

## ビルド・テスト

```bash
cd android
./gradlew testDebugUnitTest     # JVM ユニットテスト
./gradlew lintDebug             # Lint
./gradlew assembleRelease       # 署名済み Release APK
```

Release ビルドは `android/keystore/` の固定配布鍵で署名します（上書き更新のため）。
CI は GitHub App の権限の都合で [docs/ci/android.yml](docs/ci/android.yml) に定義しています。
