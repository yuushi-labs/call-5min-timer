# call-5min-timer

ahamo（1回5分以内の国内通話無料・発信対象）向けに、通話経過時間をバイブレーションと通知で知らせる Android アプリの設計書リポジトリです。

## 特徴（設計方針）

- **発信のみ対象**：無料枠の対象である発信通話だけを計測（着信では動作しない）。
- **相手が出た瞬間から計測開始**：進行中通話の通知変化（呼び出し中 → 通話開始）を検知してタイマーを開始し、開始時にも 1 回バイブ＋通知で合図する。
- **1分ごとに増えるバイブ回数**：デフォルトでは 1分=1回、2分=2回、3分=3回…と経過分数に応じた回数でバイブし、画面を見なくても経過時間が分かる。
- **4分30秒の予告アラート**：長めのバイブ＋通知音で終了間近を知らせる。
- **通知タイミング・種類の自由なカスタマイズ**：定期通知・特定時刻通知・バイブ／音／通知の組み合わせをアプリから設定可能。
- **電話帳ナビと共存**：迷惑電話対策枠（`CallScreeningService`）は使わず競合しない。
- **OPPO（ColorOS）対策**：普段はバックグラウンド常駐せず、通話イベント起点で起動して終話で即終了する省電力・タスクキル耐性設計。
- **アプリ内自動アップデート**：GitHub Releases（`yuushi-labs/call-5min-timer`）の最新リリースを確認・ダウンロードして `FileProvider` 経由で上書き更新（固定署名鍵使用）。
